# Project management

This directory holds the management side of the Pac-Man project: how the
work was planned, how it actually progressed, why the main technical
choices were made, what could have gone wrong, and how the result is
verified before a defense.

| Document | Content |
| --- | --- |
| [01-timeline.md](01-timeline.md) | Milestones, Gantt chart and Kanban board |
| [02-progress.md](02-progress.md) | Progress measured against the plan |
| [03-analysis-and-choices.md](03-analysis-and-choices.md) | Requirement analysis and the technical decisions taken |
| [04-risks.md](04-risks.md) | Risk register with mitigations |
| [05-organisation.md](05-organisation.md) | Team organisation and working rules |
| [06-acceptance-tests.md](06-acceptance-tests.md) | Acceptance test plan, run before every defense |
| [07-blocking-points.md](07-blocking-points.md) | Blocking points met and how they were unblocked |

The dates used throughout are the ones of the actual run of the project;
they are the only thing to refresh if the schedule is replayed.
